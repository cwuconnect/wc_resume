# Wild Chicken Resume Template 🐔

A deliberately fake and funny resume template featuring **Wild Chicken University**, **Coop Country**, and the eternal research question: *Why did the chicken cross the road?*

> **Important:** Every organization, credential, metric, project, and accomplishment in the sample is fictional. Replace the joke content with accurate information before using the template for a real application.

## Files

- `wild_chicken_resume.docx` — editable Microsoft Word resume
- `wild_chicken_resume.pdf` — PDF version
- `wild_chicken_resume.tex` — optional LaTeX source if you add the original template to the repository
- `README.md` — repository guide

## Sample profile

The template follows John **"Cluck"** Smith, a fictional Chicken Scientist / Poultry Engineer / Egg Enthusiast educated at Wild Chicken University in Coop Country.

It demonstrates a compact resume with a summary, experience, project, skills, education, LinkedIn, and GitHub links.

## Customize the resume

Replace the sample fields with your real:

1. Name and professional title
2. Phone, email, LinkedIn, and GitHub
3. Professional summary
4. Job titles, employers, dates, and locations
5. Accomplishment-focused bullet points
6. Projects and technologies
7. Skills
8. Education

For a real application, remove fictional claims and use only metrics and accomplishments you can support.

## Compile the LaTeX version

The source uses packages such as `geometry`, `xcolor`, `hyperref`, `enumitem`, `titlesec`, `fancyhdr`, and Source Sans Pro.

```bash
pdflatex resume.tex
```

Depending on your LaTeX environment, you may need to run the command twice.
